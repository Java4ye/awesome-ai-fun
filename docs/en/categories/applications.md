## An operating system in one HTML file

**ID**: `museum-012` · **Source**: [AI Test Museum](https://aitestmuseum.com/zh/tests/web-os-desktop) (source item 12)

Build a desktop with windows and multiple applications in a single HTML page.

**Source credit / attribution lead**: @chetaslua

**What to observe**

- Do window dragging, focus, and closing work?
- Can features such as the text editor actually be used?
- Does the result run or support the required interaction, rather than only provide a screenshot?

**Tags**: `Apps`, `UI`
